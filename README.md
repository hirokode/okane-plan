# お金計画（okane-plan）

月ごとのお金の配分を計画する、スマホ向けの小さな Web アプリです。
「今月いくら入って、何にいくら回すか」を先に決めて、最後に残る **予備費** を確認します。

- `index.html` 1 ファイルだけ（HTML・CSS・JS 同梱、ビルド不要、外部ライブラリ・CDN なし）
- データはブラウザの `localStorage` にだけ保存されます。サーバーや外部 API への通信はありません
- 初回だけパスコードを入力します（端末ごと）

## 使い方

入力は次の順番で進めます。

1. **収入見積** … この月に入ってくる見込み
2. **固定費** … 家賃・通信費など毎月ほぼ決まっている支出（支払日も記録できます）
3. **貯金・投資計画** … 先に確保する貯金・投資（種別: 現金 / 投資 / 持ち株会）
4. **変動費予算** … 食費・日用品などの月予算。「全体で入力」なら 1 つの金額だけ、「項目別に入力」ならカテゴリごとに入れます。週あたり・1日あたりの目安（項目別なら変動費内の割合も）を自動計算

最後に **予備費 ＝ 収入合計 −（固定費＋変動費予算＋貯金合計）** が出ます。
予備費がマイナスのときは、ホームと入力画面が赤くなり「いくら足りないか」を表示します。

- ホームは「＋ 入るお金」「− 出ていくお金」「％ 割合」に分けて表示します。行をタップすると、その入力画面が開きます
- 各項目の **スイッチ** を切ると、項目を消さずに集計から外せます
- 画面上部の「＋月」で新しい月を作成できます。前の月をコピーして始めることもできます
- 設定画面で、カテゴリの追加・並べ替え・削除、JSON ファイルへの書き出し／読み込み、この端末のロック解除の取り消しができます

> データはこの端末のブラウザの中にだけあります。ブラウザのデータを消すと計画も消えるので、ときどき「JSON ファイルに書き出す」でバックアップしてください。

## パスコードの設定

コードにはパスコードそのものではなく、**SHA-256 ハッシュ**（16 進数・小文字 64 文字）だけを書きます。

### 1. ハッシュを作る

**方法 A: ブラウザのコンソール**（Chrome / Safari / Firefox）

`https://` で始まる適当なページ（公開後のこのアプリなど）を開き、開発者ツールのコンソールに次の 1 行を貼り付けます。`ここにパスコード` を自分のパスコードに書き換えてから実行してください。

```js
crypto.subtle.digest('SHA-256', new TextEncoder().encode('ここにパスコード')).then(b => console.log([...new Uint8Array(b)].map(x => x.toString(16).padStart(2, '0')).join('')))
```

**方法 B: ターミナル**（macOS / Linux）

```sh
printf %s 'ここにパスコード' | shasum -a 256   # Linux なら sha256sum でも可
```

`echo` を使うと末尾に改行が入って別のハッシュになるので、`printf %s` を使ってください。

### 2. コードに書く

`index.html` の次の行を、作ったハッシュに置き換えます。

```js
const PASSCODE_HASH = '（ここに 64 文字のハッシュ）';
```

ハッシュを変えると、すでに解除済みの端末でも次に開いたときにもう一度パスコードを求められます。

### 注意

- これは「知らない人がうっかり開いても使えない」程度の簡易なロックです。ハッシュは公開されるため、短いパスコード（数字 4 桁など）は総当たりで割り出せます。**英数字を混ぜた長めのパスコード** をおすすめします
- 家計のデータはサーバーには送られず、各端末のブラウザにだけ保存されます。ほかの人がこのページを開いても、あなたのデータは見えません

## GitHub Pages で公開する

1. このリポジトリを GitHub に push する（公開リポジトリ）
2. GitHub のリポジトリページで **Settings → Pages** を開く
3. **Build and deployment** の **Source** を「Deploy from a branch」にする
4. **Branch** で `main`、フォルダは `/ (root)` を選んで **Save**
5. 1〜2 分待つと `https://<ユーザー名>.github.io/okane-plan/` で開けるようになります

スマホでは、Safari の共有メニューの「ホーム画面に追加」（Android の Chrome なら「ホーム画面に追加」）をしておくと、アプリのように開けます。

- アイコンを変えたときは、ホーム画面のアイコンを一度削除して、追加し直すと新しいアイコンになります
- iPhone では、ホーム画面から開いたアプリと Safari で開いたページは **保存場所が別** です（パスコードも別々に 1 回ずつ入力します）。Safari で入れたデータをホーム画面側に移すときは、設定の「JSON ファイルに書き出す」→ ホーム画面側で「JSON ファイルから読み込む」を使ってください

## ローカルで動かす

ビルドは不要です。`index.html` をブラウザで開くか、簡易サーバーを立てて開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```
